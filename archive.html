FIELD NOTES / THE ARCHIVE

The original
experiments.

Before this was a field guide, it was a handmade collection of questions about HTML and CSS. The 2018–2020 pages remain at their existing URLs. They are preserved as historical exhibits while their ideas get new lessons.

Why keep old code? Because learning includes understanding how practice changes. Some original pages depend on hover, fixed dimensions, an older Bootstrap release or remote images. They're archived examples, not current accessibility or performance recommendations. The revived lessons demonstrate preferred approaches.
01 / CSS GRID

The composition

A Mondrian-inspired image mosaic built from CSS Grid tracks and cell spans. It anticipated the layout tools many learners now take for granted.

The resource cards

Hover-to-reveal cards and links exploring flexible arrangement. The next chapter adds interactive controls and keyboard-accessible states.

The framework era

An example of how a framework bundled layout primitives and interface conventions into reusable components. Bootstrap 4 is historic; it isn't included as a dependency in the new field guide.

The atmospheric layers

A layered, animated composition labeled “traditional” in the old navigation. It uses positioning and transforms—not really a float layout—and inspires the new visual effects and depth lessons.

THE CONTINUING THREAD

Run it. Change it. Break it.

That invitation from the original README still guides the project. The new version builds its explanations around the same impulse: start with curiosity, inspect the source, try variations, and develop the judgment to choose the right tool for the problem.

The old pages have not been moved or deleted. Normal HTML links connect them to the new lessons, and browser back and forward navigation work exactly as you'd expect.
