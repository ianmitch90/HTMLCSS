This page really loads Bootstrap's CSS and JavaScript bundle. It demonstrates responsive columns, styled cards, a call-to-action and a native Bootstrap accordion without adding React or a client-side router.

Network boundary: Only this optional teaching page loads Bootstrap from a version-pinned CDN with Subresource Integrity. The rest of the site has no Bootstrap runtime dependency. For an offline project, download and serve a licensed, pinned distribution locally instead.
