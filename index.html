THE BIG IDEA / 001

Don't memorize.
Make sense of it.

Ever followed a tutorial, copied a snippet, and wondered why it worked? This is a different kind of learning space—part studio, part playground, part field guide.

Every experiment starts with something you can see. Change it. Notice what happens. Then uncover the code, the browser behavior, the tradeoffs, and the decisions behind it.

No magic tricks. No assumption that you already speak developer.

A DIFFERENT KIND OF SHOW-AND-TELL / 004

Beautiful is good.
Usable is better.

Design decisions are never only visual. Every lesson asks what happens when you use a keyboard, zoom in, request less motion, or load the page on a slower connection.

We don't save accessibility and performance for the last page. We make them part of the way we see.

FROM THE ARCHIVE / 005

A little history,
a lot of curiosity.

This began in 2018 as a handmade set of HTML and CSS experiments: a Grid composition, Flexbox cards, hover states, Bootstrap and an atmospheric layered scene. The point was simple: run it, change it, break it.

The original source remains in Git history. Familiar page URLs now lead to responsive, self-contained reinterpretations, with their techniques explained in the modern lessons.
