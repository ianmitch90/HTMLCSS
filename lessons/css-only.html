EXPERIMENTS / BROWSER-NATIVE INTERACTION

What can CSS do without JavaScript?

Quite a lot. Light can respond to focus. A vector can draw itself. A simple chart can change appearance, and even a miniature game can have choices. These are original, generic experiments that prove how far native HTML and CSS can go—not copies of a product interface.

What does “CSS-only” mean? The examples below use HTML inputs and CSS selectors for their visual effects and state. The shared site script supports only the optional global motion-preference toggle; no experiment uses JavaScript for its own interaction. CSS does not replace secure logic, live data handling or reliable screen-reader announcements of dynamic content.

Why layered light works

A radial gradient provides the quiet atmospheric glow. The second card adds a separate interior hairline, and the glass study introduces a reflective inset layer. A masked conic gradient becomes the running perimeter light. A separately painted edge track keeps the border stationary while a short light segment travels its perimeter once when you hover or focus within the card.

.card::before { /* ambient field */ }
.card .edge-track { /* a stationary masked border surface */ }
.card:is(:hover, :focus-within) .edge-track {
  animation: edge-run 1.6s 1 both;
}

Why it must remain optional

Big animated blurs can be expensive, and glowing edges can disappear in forced colors. The link remains visible and has a browser-native focus outline even if gradients, transitions or animation are removed.

@media (prefers-reduced-motion: reduce) {
  .card .edge-track { animation: none; }
}
Try it:

Enable the environmental light, then move focus between the three card links. Use the site's “Reduce site motion” control and verify that the cards remain understandable when the flourish stops.

02 / VECTORS AS LIVE DOCUMENTS

An SVG doesn't need a video timeline.

SVG describes shapes and paths. CSS can animate a path's stroke without a video file, canvas renderer or JavaScript animation loop. This original orbital composition is a decorative learning study, not a live loading indicator.

Inline SVGStroke-dashoffsetKeyframesSemantic alternative

VECTOR STUDY / SELF-CONTAINED

The default drawing stays complete. Enable the trace to replay the single drawing gesture, then it returns to the same static composition. Disable and re-enable it to replay. With reduced motion, the completed path remains visible without movement.

SVG is an image format. Inline SVG is especially convenient when the browser should be able to style individual shapes as part of a document.

<svg viewBox="0 0 300 255">
  <path class="trace" d="M62 126 C73 61 ..." />
</svg>
.trace { stroke-dasharray: 100; stroke-dashoffset: 0; }
.scene:has(input:checked) .trace {
  animation: draw-trace 1.6s ease-out 1 both;
}
@keyframes draw-trace { from { stroke-dashoffset: 100; } to { stroke-dashoffset: 0; } }
Accessibility and performance:

The meaningful illustration has an accessible title and description. Complex charts still need text data. SVG filters, hundreds of paths and continuous animation can be costly; prefer restrained, finite motion.

05 / ENGINEERING JUDGMENT

The impressive part isn't the trick.

The useful lesson is knowing where CSS is a better abstraction and where it isn't. Modern CSS can handle layout, motion, stylistic state and small interaction experiments elegantly. It cannot replace business logic, trustworthy data validation or every accessible interaction pattern.

Reach for CSS

Light, depth, masks, finite focus effects, small state changes and diagrams that need no computation.

Reach for JavaScript or a library

Complex game rules, analytics, live data, persistent choices, accurate announcements and application state.

Respect motion choices

Stop optional movement when users prefer less. Keep the content and state meaningful without transitions.

Measure the output

Blur, masks and compositing can still strain a GPU. Test slow devices, zoom, contrast and forced-colors mode.
