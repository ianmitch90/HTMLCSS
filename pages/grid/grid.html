Responsive doesn't mean “shrink everything.”

Responsive design means the layout adapts to the space and context available. This preview uses a separate document inside an iframe; its CSS @media rules respond to the embedded viewport width, even if you're browsing on your phone.

  • Desktop: eight columns, six rows (above 900px).
  • Tablet: six columns, seven rows (541–900px).
  • Mobile: four columns, nine rows (540px and below).

The device frames are teaching aids, not pixel-perfect emulators of particular hardware or operating systems.

One document, three arrangements.

/* Desktop is the base layout. */
.mosaic { grid-template-columns: repeat(8, 1fr); }

@media (max-width: 900px) {
  .mosaic { grid-template-columns: repeat(6, 1fr); }
}
@media (max-width: 540px) {
  .mosaic { grid-template-columns: repeat(4, 1fr); }
}

Explore the interactive Grid lab to change columns and gaps individually, or inspect the responsive preview CSS to see the actual track placement rules.

How the art stays aligned

CSS Grid defines eight equal column tracks and six row tracks. Individual spans use grid-area: row-start / column-start / row-end / column-end. This gives precise composition without positioning each tile absolutely.

.artwork {
  display: grid;
  grid-template-columns: repeat(8, 1fr);
  grid-template-rows: repeat(6, 1fr);
  gap: 8px;
}
.artwork > span:first-child {
  grid-area: 1 / 1 / 4 / 3;
}

Why this experiment matters

The original site explored Grid before it was commonplace in beginner projects. Keeping this exhibit demonstrates how two-dimensional layout can carry expressive meaning.

What to consider before using it

The grid is decorative, so it has one concise accessible description rather than nine meaningless focus targets. Keep meaningful content in logical source order, and test reflow and zoom.
