ORIGINS STUDIO / LAYERED EFFECTS

Layers create a world.

A self-contained reinterpretation of the old parallax experiment. Mountains, atmosphere and depth are shaped with CSS rather than fetched from someone else's image server.

Made new, not erased.

This exhibit reinterprets one of the original experiments in native HTML and CSS. No external photos, fonts or runtime libraries are required.

A landscape made of CSS.

Zoom into the mountains and watch the clouds disappear. Deselect to zoom back out—no JavaScript click handler is involved. Every layer is a shaped surface painted by the browser. The landscape balances angular mountain silhouettes with softer dune and ocean-like shapes. Two lightweight cloud wisps drift at staggered intervals, while gradients and a narrow haze layer add atmosphere. There's no dependency on external graphics, and the scene is decorative rather than a required source of information.

Which CSS properties make the illusion?
.scene { position: relative; overflow: hidden; }
.mountain {
  position: absolute;
  inset: 0;
  clip-path: polygon(/* mountain silhouette */);
}
.scene:has(.toggle:checked) .mountain {
  transform: scale(1.08) translateY(2%);
}

The actual page uses a native checkbox with :has() to select the scene. In older browsers without that relational selector the static illustration still works. A transform changes the apparent position or scale without changing the underlying document order. A filtered gradient adds atmosphere—but filters may increase paint or compositing costs.

Why this experiment matters

The original point was that a reversible zoom-and-clouds illusion could look like a JavaScript interaction even when it was entirely CSS-driven. This version preserves that intent without externally hosted assets.

What to consider before using it

Complex parallax, heavy blurs and large moving surfaces can affect comfort and performance. The foreground zoom remains opt-in; only the small decorative clouds drift gently by default, and motion preferences stop both effects.
