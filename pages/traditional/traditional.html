ORIGINS STUDIO / LAYERED EFFECTS

Layers create a world.

A self-contained reinterpretation of the old parallax experiment. Mountains, atmosphere and depth are shaped with CSS rather than fetched from someone else's image server.

Made new, not erased.

This exhibit reinterprets one of the original experiments in native HTML and CSS. No external photos, fonts or runtime libraries are required.

Inspect the original source ↗

A landscape made of CSS.

Try the optional depth effect, then switch it off. Every layer is a shaped surface painted by the browser. The mountains are simple polygons; the haze uses a gradient and a small blur. There's no dependency on external graphics, and the scene is decorative rather than a required source of information.

Which CSS properties make the illusion?
.scene { position: relative; overflow: hidden; }
.mountain {
  position: absolute;
  inset: 0;
  clip-path: polygon(/* mountain silhouette */);
}
.scene:has(.toggle:checked) .mountain {
  transform: scale(1.08) translateY(2%);
}

The actual page uses a native checkbox with :has() to select the scene. In older browsers without that relational selector the static illustration still works. A transform changes the apparent position or scale without changing the underlying document order. A filtered gradient adds atmosphere—but filters may increase paint or compositing costs.

Why this experiment matters

The earlier scene assembled remotely hosted image layers into a delightful parallax illusion. This version reveals the same principle without the broken-dependency risk.

What to consider before using it

Continuous parallax, heavy blurs and large fixed-size surfaces can harm comfort and performance. This page requires an explicit toggle, follows motion preferences and retains a useful static composition.
