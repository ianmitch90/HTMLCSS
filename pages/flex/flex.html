ORIGINS STUDIO / FLEXBOX

Flexible by design.

The original resource-card experiment, rebuilt using native Flexbox, local colors and visible links. It adapts to small screens and supports both keyboard and pointer exploration.

Made new, not erased.

This exhibit reinterprets one of the original experiments in native HTML and CSS. No external photos, fonts or runtime libraries are required.

Four cards, no layout magic.

The cards share space with flex: 1 1 195px: each can grow, shrink and wrap. Every link stays visible without hover. Try narrowing your browser and navigating with Tab.

How four cards share space
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}
.cards > a {
  flex: 1 1 195px;
}

This uses the browser's flex layout algorithm, not a framework or a JavaScript resize listener. The visual lift on hover and focus is optional decoration; it is not required to discover the links.

Why this experiment matters

The original cards paired resource discovery with animated reveals. This version keeps the invitation to explore while making all the destinations obvious.

What to consider before using it

Hover is not a reliable disclosure mechanism for touch or keyboard users. Prefer persistent information and visible focus; respect reduced-motion settings and minimize layout shifts.
