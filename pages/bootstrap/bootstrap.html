Then and now: The original Bootstrap 4 example loaded a CDN stylesheet and script plus remote photos. This reproduction has no Bootstrap runtime dependency. For a real Bootstrap project, follow the officially supported release's installation instructions, pin its version, and budget for updates.
Why does the actual library example live on another page?

The Origins studio is intended to survive without any CDN. The dedicated, optional starter demonstrates the real Bootstrap integration, so it can be updated deliberately without making the main educational site depend on the CDN.

Why this experiment matters

Bootstrap shows why developers use libraries: consistent component patterns, responsive primitives and less repeated work. Tailwind, Material UI, Fluent UI and headless libraries make different tradeoffs.

What to consider before using it

A framework is not a WCAG certificate, and a component library is not interchangeable with an architectural framework. Verify versions, documentation, dependencies and actual keyboard behavior.
